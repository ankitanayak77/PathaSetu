# Pathasetu Electricity pack — review rubric

No item is approved by this document. The pack remains `UNREVIEWED_DRAFT` until a named, qualified reviewer completes the review and the team records the actual approval.

For each item, the reviewer should record reviewer name/qualification, date, item ID, verdict and corrections.

1. **Science accuracy:** question, correct option, distractors and explanation align with Class 10 BSE Odisha syllabus; no misleading simplification.
2. **Concept map:** every distractor has a plausible, distinguishable misconception ID; no answer maps to an unrelated or unsupported concept.
3. **Odia clarity:** prompt, option translations and explanation read naturally to an Odia-medium Class 10 learner; no machine-sounding or ambiguous phrase remains.
4. **Bridge quality:** everyday Odia phrase, formal school Odia term and English term communicate the same concept; spelling, terminology and usage match the intended textbook context.
5. **Assessment design:** only one best answer; answer rationale explains why; distractors are plausible without relying on trick wording.
6. **Remediation:** activity directly addresses the misconception and can be completed safely offline.
7. **Release decision:** `REVIEWED` is only for a completed review. `PUBLISHED` requires all review fields and pack-level language-bridge approval. Otherwise leave `UNREVIEWED_DRAFT` or `IN_REVIEW`.

The current Odia wording is a draft to make the prototype visible. It must not be represented as teacher-reviewed.
